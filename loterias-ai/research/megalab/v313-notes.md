# MetaPleno v313 — Optimal Transport Drift

Pre-registration companion notes. No target/holdout results were inspected to design this family.

The family treats each past draw as a causal empirical measure over number-level features and tests whether transport geometry between rolling historical measures has stable out-of-sample value for ranking candidates. The design must be frozen using discovery/validation only. Holdout evaluation is permitted only after feature map, window lengths, transport metric, regularization, ranking rule and ticket construction are fixed.

Negative outcomes are first-class results. Any apparent gain that fails matched-cost null testing, correlated null testing, multiplicity correction, or era-repeat requirements must be archived as negative evidence and must not enable real-money play.
